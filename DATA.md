# Подготовка данных

1. Откройте набор [FuelConsumption на Kaggle](https://www.kaggle.com/datasets/shahulhameedkotta/fuelconsumption).
2. Скачайте CSV-файл.
3. Поместите его в корень проекта под именем `Fuel_Consumption.csv`.

Файл данных намеренно не включён в репозиторий. Это позволяет сохранить ясное происхождение данных и не переопубликовывать их без проверки условий использования.

Ожидаемые поля включают год модели, марку, модель, класс автомобиля, объём двигателя, число цилиндров, трансмиссию, тип топлива, показатели расхода и выбросы CO₂. Сценарий анализа автоматически приводит названия столбцов к верхнему регистру и удаляет пробелы по краям.
